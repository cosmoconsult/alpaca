# AL Object ID Ninja

[AL Object ID Ninja](https://alid.ninja/) is a Visual Studio Code extension for Business Central AL development. It coordinates object ID assignments across a team and provides suggestions through IntelliSense, helping developers avoid ID conflicts when working on the same codebase.

COSMO Alpaca partners with AL Object ID Ninja. COSMO Alpaca users can request an AL Object ID Ninja license as part of their subscription. To request a license, reach out to COSMO Alpaca support.

Learn more on the [AL Object ID Ninja website](https://alid.ninja/) or find the extension in the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=vjeko.vjeko-al-objid).
