# COSMO Alpaca Newsletter 11/2026

Welcome to this edition of the COSMO Alpaca Newsletter! Here's what's new and noteworthy.

---

## General

- **The COSMO Alpaca team is in the top 3 contributors of AL-Go for GitHub**

  COSMO Alpaca on GitHub builds on [*AL-Go*](https://github.com/microsoft/AL-Go) for workflows and deployment, while contributing fixes, integrations, and interfaces back to the project. Microsoft's recognition of these contributions has led to a close relationship and regular exchange with AL-Go's core maintainers — benefiting both Microsoft's project and Alpaca's continued innovation.

- **AL Object ID Ninja partnership:** COSMO Alpaca users can request an AL Object ID Ninja license as part of their subscription, helping development teams avoid object ID conflicts. Reach out to COSMO Alpaca support to request a license. [→ Read the docs](https://docs.cosmoconsult.com/en-us/cloud-service/alpaca/shared/al-object-id-ninja.html)

- **Less disruptive updates:** After updates, the Alpaca extension now shows a notification instead of automatically opening Alpaca Home. Select **Open Changelog** in the notification to see what's changed.

---

## GitHub / AL-Go

- **Containers matching workflows settings:** When creating a container for an AL-Go project, you can now choose the settings of the **CICD** (default) or **Pull Request Build** workflow, so the container matches the configuration used by that workflow. **Project Settings** remains available for the existing behavior.

- **Prerelease NuGet packages:** To try upcoming package versions before they become stable, you can now include prerelease NuGet packages in workflows and containers by appending `-allowPrerelease` to `nuGetFeedSelectMode` in your AL-Go settings. [See the AL-Go settings](https://aka.ms/algosettings#nuGetFeedSelectMode).

- **Legacy `alpaca.json` error:** AL-Go initialization now reports the legacy `.alpaca/alpaca.json` file as an error instead of a warning. Migrate its settings to AL-Go settings with the [migration guide](https://docs.cosmoconsult.com/en-us/cloud-service/alpaca/github/migrate-common-settings.html).

- **GitHub Pull Requests in VS Code:** The integration is now optional. When you choose to use its PR features, Alpaca asks whether to install GitHub's extension or open them in a browser. Your browser preference is remembered and can be set with `cosmo-alpaca.github.pullRequests.alwaysOpenInBrowser`.

---

## Azure DevOps

- **Import dashboards into an existing team:** When importing a team dashboard, you can now select an existing target team instead of creating an unnecessary team. Project dashboards continue to retain their project scope.

---
